# WaitLess Print

Online Printing and Queue Management System.

## About Project
WaitLess Print helps students place printing orders online and reduce waiting time at printing shops.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## Features
- Student Registration and Login
- Available Printing Shops
- Document Upload
- Print Cost Calculation
- Token Generation
- Queue Management
- Order Tracking
- Admin Dashboard
